# Project Rules: Custom NoiseFit Companion

1. **NO OFFICIAL APP:** Never suggest, recommend, or mention using the official NoiseFit app or servers. The user is engineering their own standalone client.
2. **REAL WORKING IMPLEMENTATIONS:** Do not write mock or simulated protocol responses. Implement the real reverse-engineered protocol over the actual connection.
3. **SELF-CONTAINED:** All features (wallpaper flashing, step sync, battery queries, notifications) must run via our custom tools, scripts, and local web app.
